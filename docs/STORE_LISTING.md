## 详细介绍

拾页帮助你在阅读网页时留下重点与自己的思考，并随时回到原文。

• 选中文字即可使用四种颜色高亮，并添加笔记。
• 保存网页标题、完整链接、原文摘录与阅读位置，从笔记库直接回到标记处。
• 截取当前可见区域，使用裁剪、矩形框、箭头、画笔和文字标注；支持下载 PNG。
• 笔记库支持全文搜索、类型和内容来源筛选，以及笔记编辑。
• 数据保存在当前浏览器本机，无需注册账号。支持 JSON 完整备份与合并恢复、Markdown 导出。
• 支持普通 HTTP / HTTPS 网页。使用本地 HTML 时，需在扩展详情开启“允许访问文件网址”。

拾页没有开发者运营的数据上传服务器、广告或分析遥测，不提供云同步。网站图标通过浏览器内部资源读取。你主动保存的笔记、网址与截图可能包含私人信息，请妥善保管和分享导出文件。

当前截图为可见区域，暂不支持整页长截图、OCR、浏览器内置页面或内置 PDF 阅读器。网页内容大幅变化时，文字定位可能回退到保存的位置。本地文件被移动或清理后，原文链接可能失效。

代码按 MIT 许可证开源。

## 单一用途

帮助用户在阅读网页或本地 HTML 时保存可追溯的高亮、笔记和标注截图，并在本机笔记库中检索、备份和返回原文位置。截图、导出和定位均服务于这一个阅读标记用途。

## 权限理由

| 权限 | 提交说明 |
| --- | --- |
| storage | 在本机保存用户主动创建的笔记、原文链接、文字定位信息、标注截图和必要临时数据。 |
| unlimitedStorage | 截图与完整备份可能超过普通本地存储配额；应用仍限制单图20MiB和笔记库140MiB。 |
| activeTab | 在用户点击工具栏并选择截图后，截取当前标签页的可见区域。 |
| scripting | 对安装前已打开的文章页补充注入选择工具及高亮样式。 |
| favicon | 在笔记库显示浏览器保存的网站图标；不使用第三方图标代理。 |
| HTTP / HTTPS 网站访问 | 为通用网页提供选区工具，并在重访文章时自动恢复已有高亮；不会建立全部浏览历史。 |
| file:///* | 在用户手动开启文件网址访问后，给本机 HTML 提供相同的标记、截图和回跳功能。 |

## 远程代码与数据

无远程可执行代码，脚本和SVG随扩展打包。不把网页内容、笔记、URL或截图发送给开发者。扩展确实在本机处理上述数据，因此隐私表单须按照实际界面定义如实填写，不能将“不向开发者传输”写成“不处理网站内容”。参见 [隐私审查](RELEASE_AUDIT.md)。

## 审核测试说明

无需账号、密码、订阅或付费。安装后打开普通文章页，选中文字保存高亮与笔记，刷新检查恢复；从工具栏打开截图，添加标记并保存；在笔记库搜索，导出JSON再合并导入，点击回到原文定位。可使用源码 demo/article.html，通过本地HTTP服务或开启文件访问后直接测试。

截图素材只使用项目自带的演示文章，不包含用户真实笔记、企业网页或浏览器个人数据。
