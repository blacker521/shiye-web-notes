# 拾页 1.0.0 发布隐私与权限核对

审查日期：2026-11-03。此文件记录当前源码的静态审查，不代表 Chrome Web Store 已批准或所有账号字段已填写。版本号为首次发布的 1.0.0，现有功能和修复保留。

## 实际数据路径

| 功能 | 代码依据 | 本机处理 / 保存 |
| --- | --- | --- |
| 选字与恢复高亮 | `anchors.js`、`content.js` | 读取正文构造临时文本索引；用户保存时记录选区原文、前后文、偏移与位置 |
| 笔记持久化 | `store.js`、`background.js` | `url`、`pageKey`、`title`、`quote`、`note`、`color`、`anchor`、`position`、ID 和时间；截图记录含图片 Data URL |
| 主动截图 | `background.js`、`screenshot.js` | 仅在用户发起后使用 `captureVisibleTab`；临时原图放 session，超额时回退 local；保存标记后的 PNG |
| 原文跳转 | `background.js`、`content.js` | session 中临时保存标签页对应笔记 ID；使用后或关闭标签页清理 |
| 导入 / 导出 | `library.js` | 用户选取 JSON 文件；可信扩展页本地暂存、后台校验后原子合并；用户发起 JSON / Markdown / 图片下载 |
| 来源图标 | `ui-icons.js` | 只构造扩展内部 `/_favicon/?pageUrl=…`；不调用第三方图标代理 |

临时截图的“24 小时”清理发生在下一次截图时，不是后台定时保证。导入暂存正常成功或失败后清理，但浏览器进程异常终止可能中断清理。不得在商店材料中宣称绝对的即时销毁或永不联网。

## 权限理由

| 权限 | 现有用途 | 申报要点 |
| --- | --- | --- |
| `storage` | 本机保存笔记、图片、截图缓存和跳转记录 | 核心用途是本地阅读标记；不是云端收集 |
| `unlimitedStorage` | 支持图片备份，避免普通存储配额过小 | 应同时说明应用仍限制单图 20 MiB、整库 140 MiB |
| `activeTab` | 用户点击工具栏后截取当前标签页 | 不申请后台屏幕录制，不持续截图 |
| `scripting` | 对安装前已打开的页面补充注入工具 | 不下载或执行远程代码 |
| `favicon` | 笔记库显示浏览器保存的网站图标 | 浏览器内部资源读取，不是图标代理服务 |
| HTTP / HTTPS 主机权限 | 普通文章中的选区工具、重访自动恢复 | 广泛页面范围来自“通用网页标记”与自动恢复需求；明确单一用途 |
| `file:///*` | 允许用户在本机 HTML 上标记和回跳 | 还需用户手动打开“允许访问文件网址”；不支持远程文件服务器 |

当前没有 `history`、`cookies`、`webRequest`、`debugger` 或持久屏幕录制权限。后台会查询打开的匹配标签页以刷新已保存标记，不能因此宣称完全不接触标签页 URL。

## Chrome Web Store 隐私披露建议

“开发者不接收数据”与“扩展不处理数据”是两个不同陈述。当前扩展确实在本机读取并保存网页摘录、笔记、URL、位置和图片。表单应与 [PRIVACY.md](../PRIVACY.md) 保持一致，不能为了显示“不收集”而隐去这些行为。

- **Website content / 网站内容**：原文摘录、用户笔记、截图直接涉及此类数据，应按提交时表单对“收集 / 使用”的具体定义如实披露本地处理。
- **Web history / 网页历史**：没有读取浏览器历史数据库，也没有建立全部访问记录；但用户保存笔记的来源 URL、标题、时间和位置会保留。若表单将保存的 URL 也纳入此类别，应披露这一范围。
- **User activity / 用户活动**：没有点击流、按键、鼠标轨迹等分析遥测。选区、用户操作与滚动位置用于核心标记和回跳；若表单定义覆盖这些本机行为，应据此申报，不能一概写“无活动处理”。
- 不主动读取身份、付款、医疗、认证信息或私人通信；用户选择的网页、笔记或截图仍可能包含这些信息。不要承诺这些信息不可能出现在用户记录中。
- 无出售、广告投放、信用评估或与核心用途无关的数据转用；无开发者服务端接收；无第三方分析 SDK。
- 先提供可公开访问的隐私政策 URL，再核对商店的单一用途、权限理由、数据使用声明与相应认证。最终复选项须以实际发布界面和当时政策为准。

## 源码与包检查

- 运行时代码未发现开发者上传端点、`XMLHttpRequest`、`sendBeacon`、WebSocket、`eval` 或 `new Function`。`library.js` 的 `fetch(note.image)` 仅用于已校验的 PNG / JPEG Data URL 转 Blob 下载。
- 扩展脚本和 SVG 资源随包提供；扩展页 CSP 为本地脚本，用户字段主要经 `textContent` 渲染。
- `chrome.storage.local` 设为 `TRUSTED_CONTEXTS`；content 消息按当前页面路径和查询参数隔离。完整笔记库由可信扩展页本地读取。
- `.gitignore` 已排除 `test-results/`、`dist/`、`node_modules/`、ZIP 和 `.DS_Store`。公开提交前仍应检查 `git diff --cached`，避免备份、真实截图、账号信息或企业文件路径误入源码。
- 测试中的 `file:///Users/demo/…`、`file:///Users/test/…` 是构造样例，不能替换成用户真实内部路径。
- Chrome 商店 ZIP 必须在根目录包含 `manifest.json`；排除测试、开发脚本、备份、仓库 `.git` 和商店截图素材。发布包应使用运行时白名单构建。
- 本审查未运行浏览器或单元测试；测试与商店素材尺寸由发布主流程复核。公开许可和素材版权仍需维护者确认。
